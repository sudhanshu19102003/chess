chess-tui

Two-player chess in the terminal, peer to peer. Both players' programs check every move; no server referees the game.

Install on macOS or Linux (x86_64 or ARM):

curl -fsSL https://chess.thesudhanshu.dev/install.sh | sh

On Windows 10 or 11 (x86_64 or ARM), in PowerShell:

irm https://chess.thesudhanshu.dev/install.ps1 | iex

Then run chess-tui in a terminal of about 146 × 50 cells.

Play a friend online: choose PEER TO PEER, host a game and send them the code. The public server at play.chess.thesudhanshu.dev only introduces you; it never sees a move.

  • The scripts install without sudo or administrator rights (to ~/.local/bin, or %LOCALAPPDATA%\Programs\chess on Windows, which is added to your PATH), and refuse any download whose signature or checksum does not match. Read them first: install.sh, install.ps1.
  • Pin a version: curl -fsSL https://chess.thesudhanshu.dev/install.sh | CHESS_VERSION=v0.1.0 sh, or on Windows $env:CHESS_VERSION = 'v0.1.0' before the command.
  • Source, releases and the full guide: github.com/sudhanshu19102003/chess
